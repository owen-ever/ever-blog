## 개선 예정

### 1. 저장소 CI 없음

- 증상: `.github/workflows`가 없어서 dev→main PR에서 lint·빌드·검사가 자동으로 돌지 않습니다.
- 원인: 확인됨. 저장소에는 PR 템플릿만 있습니다.
- 영향 범위: dev→main PR 확인 절차.
- 담당 작업: 미배정.
- 예정 버전: 미정.
- 상태: 미착수.
- 근거: `.github/pull_request_template.md`만 있음.
